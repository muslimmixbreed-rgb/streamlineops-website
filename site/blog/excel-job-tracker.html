Build a simple job tracker in Excel in an afternoon

StreamlineOps · [publish date]

If jobs, orders or requests are tracked across emails, sticky notes and memory, a single Excel sheet can bring them together. Here's a simple tracker you can build in an afternoon.

1. Decide what a "job" is

It might be a customer order, a repair, a booking or an internal task. Keep to one kind of work per tracker at first.

2. Set up your columns

Start with only what you need. You can add more later.

ColumnWhat goes in it
Job IDA simple number: 1001, 1002…
Date receivedWhen the job came in
Customer / requesterWho it's for
DescriptionA short summary
OwnerThe one person responsible
StatusChosen from a drop-down list
Due dateWhen it needs to be done
Days overdueWorked out by a formula

3. Turn it into a table

Click inside your headings and press Ctrl + T (on a Mac, Cmd + T). An Excel table gives you filter buttons, banded rows, and formulas that copy down automatically when you add a row.

4. Add a status drop-down

Select the Status column, then go to Data → Data Validation, choose List, and type something like Not started,In progress,Waiting,Done. A fixed list keeps everyone using the same words, which makes filtering reliable.

5. Work out what's overdue

In the Days overdue column, a formula like this shows how many days late an unfinished job is, and stays blank otherwise:

=IF(AND([@Status]<>"Done",[@[Due date]]<TODAY()),TODAY()-[@[Due date]],"")

The [@Column] style is how Excel tables refer to a column in the same row. If your column names differ, change them to match.

6. Make problems stand out

Select the Days overdue column and use Home → Conditional Formatting → Highlight Cells Rules → Greater Than with a value of 0. Overdue jobs now show up the moment you open the file.

7. Agree how it will be used

The spreadsheet is the easy part. The habit is what makes it work:

  • Every new job goes on the tracker the same day.
  • Each job has one owner.
  • Status is updated when it changes, not at the end of the week.
  • You look at overdue jobs together for five minutes, once a week.

Tip: store the file somewhere shared, such as OneDrive or SharePoint, so everyone works on one copy instead of emailing versions around.
